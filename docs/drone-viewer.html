Map information

RGB orthomosaics and NDVI products are grouped by meadow and ordered by the month recorded in the processed filenames. July 2026 follows these filenames, as confirmed for the folders labelled 25062026.

Panning or zooming any map updates every RGB and NDVI map of the same meadow. The two meadow areas navigate independently. North is at the top of every map.

Web previews retain the full raster footprints and are reduced to a maximum dimension of 2,048 pixels. RGB uses bilinear resampling. NDVI uses nearest-neighbour resampling and the batlow colour scale over a fixed interval from 0 to 0.8. Valid negative values receive the colour at 0, and valid values above 0.8 receive the colour at 0.8. Original GeoTIFF values and files remain unchanged.

Transparent regions correspond to source no-data or non-finite values. The supplied NDVI files declare zero as no-data; this source definition is retained in the previews. The maps provide visual comparisons, not quantitative estimates of temporal change.
